## Before Reporting an Issue

1. Check that you are running the latest version
2. Search existing GitHub Issues for duplicates
3. Review the troubleshooting documentation
4. Collect relevant information:
   - VibeCode version (Help > About)
   - Operating system and version
   - Error messages or logs
   - Steps to reproduce

## Issue Priority

| Type | Response Target |
|------|----------------|
| Security vulnerability | 24 hours (see SECURITY.md) |
| Application crash | 3 business days |
| Feature not working | 5 business days |
| Feature request | Acknowledged within 7 days |
