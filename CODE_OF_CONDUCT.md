# Code of Conduct

## Purpose

This code of conduct outlines expectations for participation in the VibeCode project. It applies to all contributors, maintainers, and community members interacting through any project channel (GitHub, email, discussions).

## Standards

We expect all participants to:

- **Be professional and respectful** in all interactions, even when disagreeing
- **Focus on technical merits** when evaluating contributions or proposals
- **Provide constructive feedback** that helps improve the work rather than diminish the person
- **Assume good intent** when interpreting others' words and actions
- **Respect boundaries** — personal attacks, harassment, and discriminatory language are never acceptable

## Unacceptable Behavior

- Personal attacks, insults, or derogatory comments
- Harassment of any kind, including sustained disruption of discussions
- Discriminatory language based on identity, background, or affiliation
- Publishing others' private information without consent
- Threats of violence or intimidation
- Any conduct that would be inappropriate in a professional workplace

## Enforcement

Violations may be reported to conduct@vibecode.dev. All reports will be reviewed and treated confidentially. Outcomes may include:

1. A private warning and request to change behavior
2. A public request to stop the behavior
3. Temporary suspension from project channels
4. Permanent ban from the project

The maintainer team reserves the right to act on behavior that violates the spirit of this code even if it does not explicitly violate a listed rule.

## Scope

This code of conduct applies to:

- GitHub issues, pull requests, and discussions
- Project email communications
- Any other project-related interaction
